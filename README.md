## AI avatar

The homepage includes a responsive Streamlit chatbot embedded from Streamlit
Community Cloud. The deployable backend and setup instructions are in
[`ai-avatar/`](ai-avatar/).

Copy `.env.example` to `.env.local` and set `REACT_APP_AI_AVATAR_URL` to the
public URL of the deployed app. Keep `OPENAI_API_KEY` only in Streamlit's
secrets.
